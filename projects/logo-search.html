Project 01

Enterprise AI Logo Search & Multimodal Retrieval Platform

Enterprise-grade multimodal AI search for sports/team logo retrieval with natural-language queries, visual similarity, hybrid retrieval and AI-powered query understanding.

Azure AI FoundryAzure MLAzure AI SearchLangChainLLMsVLMsSigLIPBGE-M3FAISSSQL ServerPythonFastAPIAzure Blob StorageMicrosoft Entra ID

Overview

Built an enterprise multimodal AI search platform enabling intelligent sports/team logo retrieval through natural language, visual similarity, and structured metadata. The system integrates LLM query understanding, VLM image analysis, dual embedding pipelines, and hybrid retrieval across Azure AI and local vector indexes.

Problem

Large logo and brand asset libraries cannot be searched effectively with keyword-only tools. Users need to find logos by natural language descriptions, visual attributes, and brand semantics — requiring unified multimodal retrieval rather than isolated text or image search.

Solution

End-to-end multimodal pipeline: image ingestion and preprocessing, VLM-based metadata generation, BGE-M3 text and SigLIP image embeddings, dual indexing in SQL Server and FAISS, LLM query understanding, hybrid lexical + semantic + visual search, metadata filtering, and reranking — served via FastAPI on Azure.

Data Ingestion & Indexing

Logo images ingested from Azure Blob Storage, validated and preprocessed for consistent format. Text vectors and metadata stored in SQL Server with Azure AI Search integration. Image vectors indexed in FAISS for fast approximate nearest-neighbor retrieval.

VLM Image Understanding

Vision-Language Models analyze each logo to generate captions and structured metadata — visual attributes, color descriptions, and semantic labels enriching searchable text beyond filenames.

Embedding Pipeline

BGE-M3 generates text embeddings from captions and metadata. SigLIP produces image embeddings for visual similarity. Dual paths enable semantic text matching and visual retrieval in parallel.

Query Understanding

LLMs parse user queries to extract intent, entities, filters, and search mode preferences. Query understanding routes requests to lexical, semantic, or visual pathways and applies metadata constraints before retrieval.

Hybrid Retrieval

Combines lexical search, semantic search (BGE-M3), and visual search (SigLIP) into a unified retrieval layer. Results merged and scored for comprehensive query coverage.

RAG

Retrieved logo metadata and captions provide context for LLM-assisted query refinement and result explanation, grounding search responses in indexed asset information.

Ranking & Reranking

Metadata filtering narrows candidates by brand, category, and attributes. A reranking stage re-scores merged results to prioritize the most relevant logos for user intent.

Azure Architecture

Deployed on Azure AI Foundry and Azure Machine Learning with Azure Blob Storage, Azure AI Search, Microsoft Entra ID authentication, and Dockerized FastAPI services.

Evaluation & Results

  • 85–90% accuracy across evaluated natural-language search scenarios
  • Hybrid retrieval outperforms single-mode search for complex multimodal queries
