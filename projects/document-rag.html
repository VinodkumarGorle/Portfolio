Project 02

Enterprise Document Q&A & RAG Platform

Self-hosted document Q&A using LLaMA-3, Mistral, Ollama, LangChain, FastAPI, and FAISS for knowledge-grounded answers.

LLaMA-3MistralOllamaLangChainRAGall-MiniLM-L6-v2Sentence TransformersFAISSFastAPIPythonSQL

Document Ingestion

Documents uploaded and parsed into clean text. The ingestion layer handles encoding, structure extraction, and preparation for chunking and embedding.

Document Parsing & Preprocessing

Multi-format documents parsed with structure-aware extraction. Preprocessing normalizes text, removes noise, and prepares content for semantic chunking.

Text Chunking & Chunk Overlap

Documents split into semantically meaningful chunks with configurable size and overlap to preserve context across chunk boundaries for multi-section questions.

Embeddings

Chunks embedded using all-MiniLM-L6-v2 and Sentence Transformers for efficient semantic similarity representation.

FAISS Vector Index

Embeddings stored in a FAISS index for fast approximate nearest-neighbor search with incremental updates as documents are added.

Semantic Retrieval & Top-K

Query embedded and compared against the vector index. Top-K retrieval returns the most semantically similar chunks assembled as LLM context.

Top-P Sampling & Similarity Thresholds

Configurable similarity thresholds filter low-relevance chunks. Generation parameters tuned for grounded, focused responses.

Prompt Engineering

Structured prompts instruct the LLM to answer only from retrieved context, improving faithfulness and reducing unsupported claims.

Reranking

Optional reranking re-scores retrieved chunks before context assembly for complex multi-topic queries.

Context Grounding & Quality

Grounding improves faithfulness, relevance, correctness, and answer accuracy while reducing hallucination.

FastAPI & LLM Inference

FastAPI exposes REST endpoints for upload, indexing, and Q&A. LLaMA-3 and Mistral run locally via Ollama for self-hosted inference without external API dependencies.
