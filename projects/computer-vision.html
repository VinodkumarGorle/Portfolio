Overview

Real-time computer vision and video analytics for object detection, tracking, people counting, and event analysis. Optimized for edge deployment using Intel OpenVINO with FP16 and INT8 quantization.

Object Detection

YOLOv5 provides fast, accurate multi-class object detection with bounding boxes and confidence scores for real-time frame processing.

Object Tracking

Detected objects tracked across frames for movement analysis, dwell time, and temporal event correlation.

People Counting

ROI-based people counting tracks entries and exits through defined zones for occupancy and foot traffic analytics.

Video Analytics

OpenCV handles frame extraction, ROI management, and visualization overlays for live monitoring pipelines.

OpenVINO & Edge AI

Intel OpenVINO optimizes YOLOv5 for edge hardware with FP16 and INT8 precision for low-latency inference on resource-constrained devices.

Inference Optimization

Model validation and inference benchmarking evaluate quantization trade-offs between accuracy and speed for production targets.

Real-Time Computer Vision

Full pipeline — frame capture, detection, tracking, ROI analysis, and post-processing — operates at real-time frame rates for live video analytics.
